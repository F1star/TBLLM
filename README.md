# 基于大语言模型的青少年综合能力评价系统

## 一、项目简介

本项目为本科毕业设计课题，旨在基于大语言模型（Large Language Model, LLM）构建一套青少年综合能力评价系统。  
系统通过对学生提交的文本材料（如作文、学习总结等）及交互式问答内容进行分析，结合预先设计的能力评价维度，自动生成多维度能力评分及文字化评价结果，为青少年能力评估提供一种智能化辅助工具。

本系统重点关注系统流程的完整性与可解释性，采用“材料输入—模型分析—结果展示”的整体架构，探索大模型在教育评价场景中的应用方式。

---

## 二、系统功能

当前系统主要包含以下功能模块：

- 用户基础功能  
  - 用户登录（简化实现，用于系统流程验证）

- 材料输入模块  
  - 支持上传 PDF / Word 等文本材料  
  - 后端自动解析文本内容  

- 模型分析模块  
  - 基于大语言模型对输入文本进行语义分析  
  - 按预设能力维度生成结构化评价结果  

- 能力评价与展示  
  - 输出多维度能力评分（如表达能力、逻辑思维能力等）  
  - 生成简要文字评价说明  
  - 以前端图表形式进行可视化展示  

---

## 三、系统架构

系统整体采用前后端分离架构，主要包括：

- 前端：  
  - 基于 Vue3 实现页面交互与结果展示  

- 后端：  
  - 基于 Flask 框架提供 RESTful API  
  - 负责文件解析、模型调用及结果处理  

- 模型层：  
  - 本地部署的大语言模型  
  - 通过 Prompt 方式引导模型输出结构化评价结果
